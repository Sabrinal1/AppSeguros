# 🛡️ Sistema de Gestión de Aseguradora

Este proyecto simula el funcionamiento de una aseguradora, permitiendo registrar clientes, emitir pólizas, calcular primas automáticamente y consultar estadísticas básicas. Fue desarrollado aplicando conceptos de **POO** como herencia, encapsulamiento y abstracción.

## 🔧 Funcionalidades

- Registro y eliminación de clientes y pólizas  
- Cálculo automático de primas  
- Control de duplicados  
- ID único para clientes y pólizas  
- Estadísticas y salida por consola descriptiva  

## 💻 Tecnologías

- Java  
- Eclipse IDE  
- Programación Orientada a Objetos

## 🧪 Pruebas

El archivo `Main.java` contiene casos de prueba ya cargados. Solo es necesario ejecutarlo desde Eclipse o IntelliJ para ver el sistema en acción, sin ingreso manual de datos.

## ⚙️ Uso

1. Descargar el proyecto  
2. Importarlo en Eclipse (`Import ▸ Existing Projects`)  
3. Ejecutar `Main.java` como aplicación Java
